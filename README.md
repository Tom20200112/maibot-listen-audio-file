# 听音频文件（MaiBot 插件）

让麦麦能听聊天里别人发的**音频文件**（mp3、m4a、wav、amr、flac、ogg 等，聊天里显示成「[文件] xxx.mp3，大小: …」的那种）和**语音条**。
听完能说出里面是说话还是唱歌、逐句听写歌词、点评音准气息、判断男声女声，再用自己的话回你。

> 麦麦平时看得到「[文件] xxx.mp3」这一行字，但听不到里面的声音；语音条最多被 MaiBot 转成文字（要开 `[voice] enable_asr`），听不出唱得怎么样。这个插件补的就是这块。

---

## 一、准备

1. **MaiBot 1.2.x 或 1.3.x**（1.2.0～1.3.99）。QQ 端用 **NapCat 或 SnowLuma 都行**：MaiBot 官方的 NapCat 适配器、SnowLuma 适配器都支持（SnowLuma 一键包自带的就是后者）。在 1.2.5 和 1.3.5 上测过。**1.2 以前的版本装不上**（插件接口不一样）。
2. **二选一，决定麦麦能听到多少：**
   - **推荐：阿里云百炼的 API Key**（用通义千问 `qwen3.5-omni-flash` 听）：能听写歌词、点评唱歌、分辨男女声。
     申请：打开 <https://bailian.console.aliyun.com/>，登录并完成实名、开通百炼，在「API Key」页面创建一个，复制那串 `sk-` 开头的字符。这串 Key 相当于钱包密码，别发到群里。
     费用按音频时长算，一首 4 分钟的歌大约用 2000 个 token，很便宜；新开通一般有免费额度，以控制台为准。
   - **不填 Key**：插件就用你在 MaiBot 里配好的**语音识别模型**（`model_config.toml` 里的 `voice` 任务）。只能把里面的话转成文字，听不出唱得怎么样。`voice` 没配的话这条路也走不通。
3. **ffmpeg**（转音频格式用）：
   - 直接装在 Linux 上的：`sudo apt install ffmpeg`。
   - Windows：下载 ffmpeg 并加进 PATH。
   - **Docker 部署的 MaiBot 镜像里没有 ffmpeg**。没有 ffmpeg 时：填了 Key 的话，小于 7MB 的 mp3/wav 照样能听，m4a 之类不行；不填 Key 的话只能听 wav。想都能听，就在容器里装上 ffmpeg（`docker exec -it <容器名> apt-get install -y ffmpeg`，重建容器后要重装）。

## 二、安装

- **插件市场**：收录后，在 MaiBot WebUI 的插件市场里搜「听音频文件」安装，然后重启 MaiBot。
- **手动装**：
  1. 从 [Releases](https://github.com/Tom20200112/maibot-listen-audio-file/releases) 下载源码包并解压，得到一个文件夹（里面有 `plugin.py` 和 `_manifest.json`）。
  2. 把这个**文件夹**整个放进 MaiBot 的 `plugins/` 目录里（放好后是 `plugins/<文件夹>/plugin.py` 这样的路径）。
  3. **重启 MaiBot**。日志里看到插件「听音频文件」加载成功就好了。第一次加载后会自动在文件夹里生成 `config.toml`。

## 三、填配置（填 Key 才需要）

两种办法，任选一个：
- **WebUI**：在插件管理里找到「听音频文件」，打开它的配置，把 `llm` 里的 `api_key` 填上，保存。
- **直接改文件**：打开 `plugins/listen_audio_file/config.toml`，找到 `[llm]` 下的 `api_key = ""`，把 Key 填进引号里，保存后重启 MaiBot。

| 配置项 | 默认 | 说明 |
|---|---|---|
| `[llm] api_key` | 空 | 百炼 Key；不填就用 MaiBot 自己的语音识别（只能转文字） |
| `[llm] base_url` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 一般不用改；百炼控制台给你的调用地址不一样就填那个。**Key 会发到这个地址，别填不可信的** |
| `[llm] model` | `qwen3.5-omni-flash` | 想听得更细可换 `qwen3.5-omni-plus`（更慢更贵） |
| `[listen] max_seconds` | 600 | 最长听多少秒 |
| `[listen] include_voice` | true | 也能听语音条（收到语音条会在本地存一份副本）；关掉就只管音频文件 |
| `[listen] cache_on_arrival` | true | **建议开着**：收到音频文件或语音条就先存一份。QQ 文件的下载链接大约 13 小时就失效，群文件也常被删，存了以后才听得到 |
| `[listen] keep_days` | 7 | 存的副本留几天 |
| `[listen] allow_private_network` | false | 允许从本机/内网地址下载音频。**只在本机测试时打开**，平时开着的话，有人伪造链接就能让麦麦去访问你的内网 |

## 四、怎么用

- **最常用**：有人发了音频文件或语音条之后，@麦麦 说一句「听听刚才那首」「这条语音唱得怎么样」。麦麦会自己去听（工具名 `listen_audio_file`），再回你。
- **指定听哪个**：回复那条消息再 @麦麦，或者直接说「听听那个 xxx.mp3」「听听刚才那条语音」。
- **想让它重点听什么就直说**：「逐句听写歌词」「帮我听听音准和气息」「是男声还是女声」。
- **手动测试**：发 `/听音频`，会直接把这个聊天最近一个音频文件或语音条的听感回出来（不经过麦麦的人设）；也可以写 `/听音频 逐句听写歌词`。

**语音条和 MaiBot 自带的语音识别是什么关系？** MaiBot 打开 `[voice] enable_asr` 后，每条语音都会自动转成文字，麦麦能看懂说了什么，但听不出唱得怎么样、是男声还是女声、语气如何。这个插件不自动听，麦麦想细听或者有人让她听时才调工具。两个可以同时开，互不影响。

## 五、要知道的几件事

- 「最近有哪些音频」的名单在插件装好之后才开始记，重启后清空。不过按 msg_id 找的话，库里的旧消息也能找到（之前存过副本、链接还活着、群文件还在、或者 QQ 端还查得到那条语音就能听）。
- 语音条的副本存在插件自己的数据目录里，超过 `keep_days` 天自动删除，不会发到别处；只有被听的那一条才会发给百炼。
- 只是发个文件、不叫麦麦，她不一定会去听，跟平时的回复规则一样。
- 填了 Key 的话，音频会发到阿里云百炼去识别，介意隐私的内容别让它听。
- 听的结果是模型听出来的，歌名/原唱它经常猜错，插件已经提醒麦麦别说死。
- 插件只认 QQ 端确认过的真文件消息：有人在聊天里手打一行「[文件] …，链接: …」不会被当成文件。下载只走公网地址。
- 源码和问题反馈：<https://github.com/Tom20200112/maibot-listen-audio-file>（提 issue 时附上日志里「听音频文件」那几行）。

## 六、出问题了看哪

MaiBot 日志里搜 **「听音频文件」**，能看到记下了哪些文件、下载或识别失败的原因。

## 七、更新记录

- **1.1.1**：采纳插件中心第二轮审核建议：群文件重取拿到的地址只认 http(s) 网址。
- **1.1.0**：
  - **也能听语音条了**。收到语音条时插件先存一份，有人让麦麦听、或者她自己想细听时调同一个工具；`/听音频` 也认语音条。新增配置项 `include_voice`（默认开）。
  - 采纳插件中心审核的两条建议：下载时连接用的就是检查过的地址（防 DNS 重绑定）；说明里提醒 `base_url` 别填不可信的地址。
  - 下载出网络错误时给出看得懂的提示。
- **1.0.2**（安全加固，建议升级）：
  - 只认 QQ 端确认过的真文件消息。以前有人在聊天里手打一行「[文件] …，链接: …」，插件会照着去下载那个链接。
  - 下载只走公网地址，跳转也逐跳检查，不会被引去访问本机、内网或云服务器的元数据地址。
  - ffmpeg 只读本地文件。
  - 新增配置项 `allow_private_network`，默认关，只在本机测试时打开。
- **1.0.1**：
  - 支持 MaiBot 1.3.x 和 SnowLuma（1.0.0 在 1.3 上会因为版本号被拒绝加载）。
  - 麦麦偶尔会把「想重点听什么」错填进消息编号（MaiBot 1.3 默认的 deepseek-v4-flash 实测出现过），1.0.0 会因此说「没找到」，麦麦就在群里说听不了；现在改成照样去听这个聊天最近的音频文件。
  - QQ 消息编号大约一半是负数，1.0.0 对这类消息在下载链接过期后没法再从群文件重新取，已修。
  - 升级方法：把旧的 `plugins/listen_audio_file` 文件夹里除 `config.toml` 以外的文件换成新的，重启 MaiBot。
- **1.0.0**：首个版本。
